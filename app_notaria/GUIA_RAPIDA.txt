PASO 1: INSTALAR GIT (Si no lo tienes)

Descarga desde: https://git-scm.com/download/win

Verifica la instalación:
  Abre PowerShell y escribe: git --version


════════════════════════════════════════════════════════════════
PASO 2: HACER EL PRIMER COMMIT
════════════════════════════════════════════════════════════════

En PowerShell, ve al directorio del proyecto y ejecuta:

  cd c:\Users\EQUIPO 25\Desktop\Beneficencia\app_notaria
  powershell -ExecutionPolicy Bypass -File first-commit.ps1

Este script:
  ✓ Inicializa el repositorio git
  ✓ Configura tu usuario de git
  ✓ Agrega todos los archivos
  ✓ Hace el primer commit
  ✓ (Opcional) Conecta con repositorio remoto


════════════════════════════════════════════════════════════════
PASO 3: CONFIGURAR PRODUCCIÓN
════════════════════════════════════════════════════════════════

Edita el archivo: production.env

Cambia estos valores con tus credenciales REALES:

  SUPABASE_URL=https://tu-proyecto.supabase.co
  SUPABASE_KEY=tu-anon-key
  SUPABASE_SERVICE_ROLE_KEY=tu-service-role-key

⚠️ IMPORTANTE: Estos archivos NO se suben a git


════════════════════════════════════════════════════════════════
PASO 4: DESPLEGAR A PRODUCCIÓN (SIN ABRIR VISUAL STUDIO)
════════════════════════════════════════════════════════════════

Abre PowerShell y ejecuta:

  cd c:\Users\EQUIPO 25\Desktop\Beneficencia\app_notaria
  powershell -ExecutionPolicy Bypass -File deploy.ps1 start

Eso es todo. La aplicación estará corriendo en:

  🌐 http://localhost:8000
  📚 Docs: http://localhost:8000/docs

SOLUCIÓN DE PROBLEMAS COMUNES
════════════════════════════════════════════════════════════════

❌ "Git no está instalado"
   → Descarga desde: https://git-scm.com/download/win
   → Reinicia PowerShell después de instalar

❌ "No puedo acceder a http://localhost:8000"
   → El servidor tarda 30 segundos en iniciar
   → Espera y recarga la página
   → Verifica que no haya otro proceso en puerto 8000

❌ "No hay datos en la aplicación"
   → Crea la tabla en Supabase: supabase_schema_from_excel.sql
   → Importa datos: python import_liq_from_excel.py
   → Verifica credenciales en production.env

❌ "Error de conexión a Supabase"
   → Verifica que SUPABASE_URL sea correcta
   → Verifica que SUPABASE_KEY sea válida
   → Verifica que tengas internet
