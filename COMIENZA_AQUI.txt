PASO 1: Instalar Git (si no lo tienes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Reinicia PowerShell después de instalar


PASO 2: Hacer el primer commit
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   En PowerShell (en la carpeta del proyecto):
   
   powershell -ExecutionPolicy Bypass -File first-commit.ps1
   
   Este script:
   ✓ Verifica Git
   ✓ Configura tu usuario
   ✓ Inicializa repositorio
   ✓ Hace primer commit
   ✓ (Opcional) Conecta con GitHub/GitLab


PASO 3: Desplegar a producción
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   En PowerShell (en la carpeta del proyecto):
   
   powershell -ExecutionPolicy Bypass -File deploy.ps1 start
   
   La aplicación estará en: http://localhost:8000

DESPLIEGUE:
  powershell -ExecutionPolicy Bypass -File deploy.ps1 start      # Iniciar

  git commit -m "mensaje"       # Hacer commit
  git push                      # Subir cambios
  git log --oneline -5          # Ver últimos 5 commits

┌───────────────────────────────────────────────────────────────────┐
│ 🆘 SOLUCIÓN DE PROBLEMAS                                           │
└───────────────────────────────────────────────────────────────────┘

❌ "Git no encontrado"
   → Instala desde https://git-scm.com/download/win
   → Reinicia PowerShell

❌ "No funciona el script"
   → Abre PowerShell como administrador
   → Ejecuta: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned
   → Luego intenta nuevamente

❌ "Puerto 8000 en uso"
   → En deploy.ps1, cambia PORT=8000 a otro número
   → Por ejemplo: PORT=8001

❌ "No hay datos en la app"
   → Importa datos: python import_liq_from_excel.py --excel archivo.xlsx
   → Verifica que la tabla exista en Supabase
